## 🖥️ About

PortfolioOS is a fully interactive personal portfolio designed to simulate a Linux desktop environment.

Users can:

- Open desktop applications
- Navigate using terminal commands
- Explore skills, projects and certifications
- View interactive windows
- Experience Linux-inspired UI animations
- Access information through both GUI and CLI modes

# 🧠 Terminal Guide

The portfolio includes a command-driven terminal.

## Available Commands

| Command | Description |
|----------|------------|
| help | Display available commands |
| about | Open profile information |
| skills | Open skills application |
| contact | Open contact information |
| projects | View projects |
| resume | Download/View Resume |
| clear | Clear terminal |
| sudo admin | Enter admin mode |

### Example

```bash
portfolio@user:~$ help

Available Commands:

about
skills
contact
projects
resume
clear
sudo admin
```
